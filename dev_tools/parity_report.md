## Key Findings

### Root Cause of Dead Buttons (New Window)
The new window (`MainWindow` in `slitra_window.py`) uses a **signal-based architecture**:
- Buttons in `TopBar` emit signals (`calculate_requested`, `clear_requested`, etc.)
- A separate `SlitraController` connects to these signals and implements the logic
- **When running `ui_qt.py --new` directly, the controller is NOT created**, so signals have no receivers!

The old window (`CoilSlittingCalculator` in `ui_qt.py`) has handlers as methods directly on the class, so buttons work immediately.

### Logo Issue
- Old window: Loads `logo.png` via `get_resource_path()` and displays it on `logo_label`
- New window: Uses `LogoMark` class that paints a red "CS" square

### Input Panel Differences
- Old: 8 coil count options (1-8), avg weight is editable input, checkbox checked by default
- New: 3 coil count options (1-3), avg weight is editable input, checkbox unchecked by default
- Both: Size edits created dynamically based on count

### Fit Meter
- Both show "Coil width (mm):" label but not the actual fit meter text ("X / W mm")
- The fit meter bar and text need to be implemented
